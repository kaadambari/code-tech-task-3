# Threat Intelligence Web Scraper

**Internship:** CodeTech IT Solutions  
**Task:** Task 3  
**Language:** Python  

## Overview
A Python-based threat intelligence scraping script that fetches raw cyber threat feeds and parses key indicators of compromise (IoCs), such as malicious IP addresses, using regular expressions.

## Features
- Fetches real-time open-source threat intelligence (OSINT) data
- Parses and extracts IP indicators using pattern matching (`re` module)
- Displays structured output for security analyst review

## How to Run
1. Open a terminal inside the project directory.
2. Run the script:
   ```bash
   python threat_scraper.py
